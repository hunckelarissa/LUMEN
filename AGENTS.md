# AGENTS.md — контекст для AI-агентов

## Что это за проект

LUMEN — проектируемый язык программирования (метаморфная парадигма, killer feature — `morph`-блок).
**Статус: стадия проектирования.** Интерпретатор не реализован; в `src/lumen/` — только CLI-заглушка (баннер + версия).

## Источники истины (в порядке приоритета)

1. `docs/lumen_spec.md` — формализованная спецификация (EBNF, семантика, ошибки, примеры). Главный документ.
2. `docs/lumen_tz.md` — техническое задание, критерии приёмки v0.1.
3. `docs/lumen_todo.md` — пошаговый план реализации интерпретатора (12 этапов, псевдокод, тесты).
4. `docs/lumen_open_questions.md` — открытые вопросы; при принятии решения фиксировать здесь и переносить в спецификацию.
5. `ROADMAP.md` — этапы и границы версий.

Производные/обзорные документы (не редактировать без синхронизации с источником): `docs/core-language-specification.md` (выжимка из spec), README.

## Правила работы

- Реализацию вести строго по `docs/lumen_todo.md`; стек — Python 3.10+, только стандартная библиотека, ручной рекурсивный спуск.
- Тесты обязательны (`pytest tests/`); golden-тесты — `.lumen` + `.expected`.
- Примеры языка — в `examples/*.lumen`; они соответствуют §VI спецификации.
- При изменении поведения языка обновлять: spec → builtins/errors справочники → примеры → CHANGELOG.md.
- Папка `research/` — исторические материалы и переписки; контекст «почему», не источник требований.
- Каталог `.gigacode/` — служебный, не трогать.
- Явная метаморфность обязательна внутри morph-блоков; неявные трансформации допустимы вне их («два режима», spec §3.2).
