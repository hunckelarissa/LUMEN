# 🌊 1. Data Pipeline: чистка → нормализация → фичи

Этот пример показывает **эволюцию данных** как первоклассную сущность.

```lumen
morph dataset
  state rows: Table
  state features: Matrix

  transform "clean"
    state.rows = remove_nulls(state.rows)
    state.cleaned = true
  end

  transform "normalize"
    skip if state.cleaned == false
    state.rows = scale(state.rows, method: "zscore")
  end

  transform "extract_features"
    state.features = pca(state.rows, components: 12)
  end
end

print(dataset.history)
```

**Что демонстрирует:**
- явные шаги  
- условные пропуски  
- живое состояние  
- встроенную историю трансформаций

# 🤖 2. Агент: наблюдение → решение → действие

Этот пример показывает, что LUMEN идеально ложится на архитектуру LLM‑агентов.

```lumen
morph agent
  state goal: String
  state memory: List
  state observation: Any
  state action: Any

  transform "observe"
    state.observation = sense_environment()
  end

  transform "reason"
    state.action = llm.decide(
      goal: state.goal,
      observation: state.observation,
      memory: state.memory
    )
  end

  transform "act"
    result = execute(state.action)
    state.memory.append({action: state.action, result: result})
  end
end

loop every 2s
  agent.run_cycle()
end
```

**Что демонстрирует:**
- morph‑блок как цикл агента  
- состояние как память  
- шаги как этапы reasoning

# 🔁 3. State Machine: простой, читаемый, без boilerplate

Этот пример показывает, что конечные автоматы в LUMEN выглядят естественно.

```lumen
morph door
  state status: "closed"

  transform "open"
    require state.status == "closed"
    state.status = "open"
  end

  transform "close"
    require state.status == "open"
    state.status = "closed"
  end

  transform "lock"
    require state.status == "closed"
    state.status = "locked"
  end

  transform "unlock"
    require state.status == "locked"
    state.status = "closed"
  end
end

door.open()
door.lock()   # ошибка: нельзя запереть открытую дверь
```

**Что демонстрирует:**
- morph‑блок как state machine  
- `require` как встроенная проверка переходов  
- ошибки переходов встроены в семантику

# 🎹 4. Live‑coding: свободный режим, как BASIC или SuperCollider

Этот пример показывает, что LUMEN может быть лёгким и игривым.

```lumen
x = 1
x = "hello"
grow x with " world"
print(x)   # "hello world"

morph beat
  state bpm: 120

  transform "faster"
    state.bpm += 10
  end

  transform "slower"
    state.bpm -= 10
  end
end

loop
  play_kick(beat.bpm)
  sleep(60 / beat.bpm)
end
```

**Что демонстрирует:**
- свободная динамика вне morph  
- morph как живой объект, влияющий на исполнение  
- язык подходит для интерактивного творчества
