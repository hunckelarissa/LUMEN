1.1 Философия

Lumen — это:

реальный язык программирования

минималистичный, но расширяемый

понятный новичкам

ориентированный на самовыражение

живой и эволюционирующий

Язык, построенный вокруг трансформации и изменения.

4. Формальная структура языка
4.1 Лексика

Типы токенов:

IDENTIFIER
NUMBER
STRING
KEYWORD
OPERATOR
SEPARATOR
4.2 Грамматика (EBNF)
program     = { statement }

statement   =
      assignment
    | if_stmt
    | loop_stmt
    | func_def
    | expr

assignment  =
      IDENTIFIER "=" expr

if_stmt     =
      "if" expr block ["else" block]

loop_stmt   =
      "loop" expr block

func_def    =
      "func" IDENTIFIER "(" [params] ")" block

params      =
      IDENTIFIER { "," IDENTIFIER }

block       =
      ":" { statement }

expr        =
      term { ("+"|"-") term }

term        =
      factor { ("*"|"/") factor }

factor      =
      NUMBER
    | STRING
    | IDENTIFIER
    | "(" expr ")"

13. Что из переписки особенно важно

Три ключевых принципа:

1. Реальность

Язык должен использоваться, а не быть шуткой.

2. Простота

Новичок должен начать писать код через 10 минут.

3. Документация

Документация — часть языка.
