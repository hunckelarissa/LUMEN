Lumen Programming Language
Formal Language Specification (Draft 1)
1. Общая модель языка

Lumen — это интерпретируемый высокоуровневый язык программирования общего назначения.

Основные характеристики:

Свойство	Значение
типизация	динамическая + опциональная статическая
парадигма	мультипарадигменная
выполнение	интерпретация
блоки	ключевые слова end
модули	файловые

11. Условный оператор
Синтаксис
if expression
    statements
end
С веткой else
if x > 10
    print("big")
else
    print("small")
end
12. Циклы
Универсальный цикл
loop condition
    statements
end

Пример:

let i = 0

loop i < 10
    print(i)
    i = i + 1
end
13. Функции
Определение

end

Пример

17. Трансформации (уникальная концепция)

Специальная конструкция:

transform variable -> expression

Пример:

let x = 10

transform x -> x * 2

эквивалентно

x = x * 2
18. Оператор become

Изменяет тип или структуру значения.

become value as type

Пример:

become x as string
19. Grow

Используется для постепенного накопления.

grow variable with value

пример

grow total with 10

эквивалент:

total = total + 10

24. Формальная грамматика (EBNF)
program      = { statement }

statement    =
      variable_decl
    | assignment
    | if_stmt
    | loop_stmt
    | func_def
    | return_stmt
    | expr

variable_decl =
      "let" IDENTIFIER "=" expr

assignment   =
      IDENTIFIER "=" expr

if_stmt =
      "if" expr block ["else" block] "end"

loop_stmt =
      "loop" expr block "end"

func_def =
      "func" IDENTIFIER "(" [params] ")" block "end"

block =
      { statement }

params =
      IDENTIFIER { "," IDENTIFIER }

expr =
      term { ("+" | "-") term }

term =
      factor { ("*" | "/") factor }

factor =
      NUMBER
    | STRING
    | IDENTIFIER
    | "(" expr ")"
